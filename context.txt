# CONTEXTO SOBRE PROPHET LABS
Prophet Labs es una plataforma de vanguardia ("terminal") diseñada para identificar y aprovechar oportunidades de ARBITRAJE EN TIEMPO REAL en mercados predictivos. 
Sus características clave incluyen:
1. Integración Multi-Plataforma: Extrae datos en vivo de 4 mercados principales: Polymarket, Opinion Labs, Kalshi y Predict.
2. Detección de Arbitraje: Compara las cuotas ("prices", "yes/no tokens") entre estas plataformas sobre un mismo evento. Calcula automáticamente el "Spread" (diferencial) y el "ROI" (retorno de inversión) potencial.
3. Arquitectura Robusta: Backend en Python (FastAPI) con un sistema de Proxy para evadir restricciones (soporta firmas RSA complejas como las de Kalshi v2) y Frontend React ultra-rápido y con estética Premium ("Glassmorphism", Dark Mode, interfaces inmersivas y animaciones ricas).
4. Validación con IA (LLM + Pro Alerts): Utiliza Modelos de Lenguaje (como MiniMax/Gemini/OpenAI) para interpretar variaciones sutiles en los nombres y reglas de los mercados y validar automáticamente si dos mercados de plataformas distintas equivalen realmente al mismo evento (para evitar "falsos arbitrajes").
